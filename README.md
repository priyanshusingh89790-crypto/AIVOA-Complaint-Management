AI-powered Customer Complaint Management System for pharmaceutical manufacturing.

### Frontend
- React
- Vite
- Redux Toolkit
- Tailwind CSS

### Backend
- Python
- FastAPI
- LangGraph
- Groq
- Gemma 2 9B

### Database
- PostgreSQL

## Architecture

React → FastAPI → LangGraph → Groq/Gemma → PostgreSQL
